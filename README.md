## Featured Projects

### [Workflow — Spec\-Driven AI Agent Orchestration](https://github.com/lucasrasia/workflow)

A reusable framework that organizes AI\-assisted software development around specifications, specialized agent roles, and verifiable evidence\.

- Defines roles for implementation, independent review, correction, and testing\.
- Tracks execution through dispatch contracts, state records, and validation matrices proportional to risk\.
- Includes integrity checks for vendored agent resources and explicit user decisions before completion and release\.

**Focus:** AI agents, specification\-driven development, software quality, and traceability\.

### [WidgetaAI — Codex Usage Desktop Overlay](https://github.com/lucasrasia/widget_AI)

A compact Windows overlay that displays Codex account rate limits and aggregate token activity through the local Codex App Server\.

- Shows usage limits, reset times, and token\-counter changes over named monitoring periods\.
- Uses an animated mascot to indicate activity inferred from fresh usage readings\.
- Preserves the last successful snapshot when a refresh fails and marks it as stale\.

**Built with:** React, TypeScript, Tauri, Rust, and Vite\.

### [WordAnki — Vocabulary Learning with Spaced Repetition](https://github.com/lucasrasia/WordAnki)

A full\-stack application for learning English vocabulary through flashcards and scheduled reviews\.

- Adjusts review intervals based on incorrect, difficult, or easy responses\.
- Provides a REST API for vocabulary management, due reviews, and learning progress\.
- Combines a React interface with persistent storage in SQLite\.

**Built with:** Python, FastAPI, SQLAlchemy, SQLite, React, Vite, and Tailwind CSS\.

### [CNN Study — Handwritten Digit Classification](https://github.com/lucasrasia/CNN_study)

A learning notebook for building and training a convolutional neural network on MNIST\.

- Explores image normalization, class distribution, and train/validation splits\.
- Combines convolution, max pooling, dropout, and a softmax classification layer\.
- Uses early stopping and model checkpoints during training\.

**Built with:** Python, Keras, TensorFlow, NumPy, and Matplotlib\.
